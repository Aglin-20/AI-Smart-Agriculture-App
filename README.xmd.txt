# AI Smart Agriculture App 🌱

An AI-powered crop recommendation system that predicts the best crop for cultivation based on soil nutrients and environmental conditions.

## Features
- Predicts suitable crops using Machine Learning
- Uses Nitrogen, Phosphorus, Potassium values
- Considers temperature, humidity, pH, and rainfall
- Provides profitable crop recommendation
- User-friendly interface built with Streamlit

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Dataset Attributes
- N (Nitrogen)
- P (Phosphorus)
- K (Potassium)
- Temperature
- Humidity
- pH
- Rainfall

## Run Project
streamlit run app.py
